# Hyping Marker Dictionaries (Reconstruction)

> ⚠️ **Read this first.** arXiv:2608.00045 does **not** publish its dictionaries. The paper states only their sizes — **88 acronyms, 145 buzzwords, 127 jargon words** — and describes them as "custom-built" and tailorable. The lists below are therefore a **reconstruction** written for this skill, not the paper's original lists.
>
> Consequence: densities computed here are **directionally comparable** to the paper's bands, not numerically identical. Report results as "within the paper's band" — never as "the paper's value".

The `screen` script parses this file. Section headings `##` define dictionary names; each `- term` bullet is one entry. Edit the lists freely — the paper explicitly invites tailoring dictionaries to a sector or hype cycle.
